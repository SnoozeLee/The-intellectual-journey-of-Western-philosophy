# 教学设计与思辨对话实录·协作规范 (AGENTS.md)

> **定位与宗旨**：  
> 本规范专用于约束和指导 `教学设计/` 目录下的所有教学理论产出、苏格拉底式哲学探究对话及实录归档。确保后续任何 Agent 在切换会话或接力维护时，严格遵循既定的学习科学范式、交互边界与文档组织标准。

---

## 一、 对话引导铁律 (Socratic Dialogic Rules)

在与学习者展开哲学探究对话时，Agent 必须无条件遵守以下核心原则（详见 [对话式哲学探究教学设计指南.md](./对话式哲学探究教学设计指南.md)）：

1. **坚持“接生”而非“灌输”**：
   - 严禁教师独白式的长篇大论。教学的核心目标是**通过精心设计的情境冲突与两难反问，制造认知失衡，引导学习者自己顿悟出哲学之境**。
2. **绝对禁言期（严禁提前剧透）**：
   - 在学习者尚未用自己的语言说出本质机理之前，**绝对严禁提前抛出哲学家姓名（如康德、休谟、黑格尔、笛卡尔等）和专业哲学术语**。
3. **极简聚焦模式（严格控制认知负荷 CLT）**：
   - **每轮对话只抛出 1 个关键情境追问或认知冲突点**。
   - 严禁并列三四个连环问题，严禁堆砌冗余分析，严格保护学习者的工作记忆不被挤爆。
4. **延迟结晶与理论挂载**：
   - 唯有当学习者亲口推导出关键机制（Aha-Moment）之后，引导者才给予充分确认，并正式引入哲学思想史的对应概念进行学术结晶与映射。

## 二、 实录文档结构与排版规范 (Transcript Document Standards)

所有沉淀在 `教学设计/` 下的对话实录文档，必须严格遵循统一的命名与四段式结构：

### 1. 文件命名与编号规范
- 格式：`{序号}_实录_{主题简称}思辨对话.md`
- 范例：
  - `01_实录_诺基亚与移动终端思辨对话.md`
  - `02_实录_AI与主体性危机思辨对话.md`
  - `03_实录_亲密关系与情感博弈思辨对话.md`

### 2. 正文结构与命名铁律
每篇实录必须按序包含以下模块，**严禁混淆正文与附录的命名**：

1. **元信息与导读**：包含实录说明、快速导航（指南、前后联动实录、对应哲学透镜、关联讲次）。
2. **第一章：思辨阶梯总览与顿悟映射 (`## 一、 思辨阶梯总览与顿悟映射`)**：
   - 使用 Mermaid 流程图，左侧呈现“学习者自主推演阶梯”，右侧映射“对应西方哲学核心概念”。
3. **第二章：回答实录与教学法拆解 (`## 二、 回答实录与教学法拆解`)**：
   - **标题约束**：**必须叫“回答实录与教学法拆解”**，**严禁**冠以“全程实录”之名。
   - **内容要点**：按幕次（Act）推进，标明【教学意图】、引导者提问精要、学习者原始回答高光引用，以及【理论结晶】。
4. **第三章：核心教学收获 (`## 三、 本次实录的核心教学收获`)**：
   - 提炼 3 点深层认知突破与元认知启示。
5. **文末附录：对话全程实录（一字不差完整版） (`## 附录：对话全程实录（一字不差完整版）`)**：
   - **核心要求**：必须在文章末尾独立成章，**一字不差地完整复原对话全程的原始记录**！
   - **涵盖要素**：引导者的完整提问铺垫、所有 Mermaid 图表、学习者的完整作答与题外话随感、引导者的完整长篇评价与理论结晶。
   - **排版模式**：采用优雅卡片流（标准 Markdown 排版），清晰划分每轮交互的【引导者发言（原始完整记录）】与【学习者发言（原始完整记录）】。

## 三、 路径引用与 Git 版本控制规范

1. **强制统一标准相对路径**：
   - 绝对禁止写入本地盘符（`C:/`、`k:/`）或 `file:///` 协议绝对路径；
   - 目录内互链使用 `./`，跨目录引用使用 `../哲学透镜/...` 或 `../{讲次}_结构化深度探究.md`。
2. **精准提交原则（严格执行根目录 AGENTS.md 规则 4）**：
   - Git 提交时，**只携带和本次任务直接相关的文件修改**；
   - 严禁将未受命或工作区其他散落的修改随手打包提交；
   - 提交信息遵循 Conventional Commits：`docs(pedagogy): ...`。
